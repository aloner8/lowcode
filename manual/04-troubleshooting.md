# แก้ปัญหาที่พบบ่อย

---

## เข้าสู่ระบบไม่ได้

### ขึ้นว่า "อีเมล/ชื่อผู้ใช้ หรือรหัสผ่านไม่ถูกต้อง"

1. ลองใช้ **อีเมล** แทนชื่อผู้ใช้ (ใช้ได้ทั้งสองอย่าง)
2. ตรวจว่าเปิด **Caps Lock** อยู่หรือไม่ — หน้าเข้าสู่ระบบจะเตือนให้
3. กดไอคอนรูปตา **แสดงรหัสผ่าน** เพื่อดูว่าพิมพ์ถูก

### ขึ้นว่า "พยายามเข้าสู่ระบบบ่อยเกินไป"

ระบบล็อกชั่วคราวหลังใส่รหัสผิดหลายครั้ง เพื่อกันคนเดารหัสผ่าน

- **รอตามเวลาที่แจ้ง** แล้วลองใหม่
- ถ้าเร่งด่วน ให้ GOD ปลดล็อกจาก `/admin/security`

### เด้งกลับหน้าเข้าสู่ระบบตลอด

Session หมดอายุ (8 ชั่วโมง) หรือมีการเปลี่ยนค่าความปลอดภัยของระบบ
**ปิดแท็บเดิมทิ้ง** เปิดใหม่แล้วเข้าสู่ระบบอีกครั้ง

---

## เข้าหน้าไหนก็เด้งไปหน้าเปลี่ยนรหัสผ่าน

บัญชียังใช้รหัสผ่านที่ระบบตั้งให้ตอนสร้าง — เป็นขั้นตอนบังคับ ข้ามไม่ได้

ตั้งรหัสของคุณเองแล้วจะใช้งานได้ตามปกติ ระบบจะพาไปหน้าถัดไปให้อัตโนมัติ

---

## กดปุ่มแล้วขึ้น "Server Action ... was not found"

เกิดจาก**แท็บที่เปิดค้างไว้ก่อนระบบอัปเดต** ไม่ใช่ข้อมูลเสียหาย

**ปิดแท็บนั้นทิ้ง** แล้วเปิดใหม่ (Safari ต้องปิดแท็บ กด refresh เฉย ๆ มักไม่พอ)

---

## ข่าวที่เพิ่มไม่ขึ้นเว็บ

ไล่ตามลำดับนี้

1. **สถานะ** เป็น "เผยแพร่" หรือยัง
2. **วันที่เผยแพร่** ตั้งเป็นอนาคตหรือเปล่า
3. **หมวดหมู่** ตรงกับหน้าที่กำลังดูไหม
4. กด **refresh** ที่หน้าเว็บจริง

ยังไม่ขึ้น → แจ้ง ADMIN ให้ตรวจว่าต้อง Build Runtime หรือไม่

---

## รูปที่อัปโหลดไม่แสดง

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| อัปโหลดไม่ผ่าน | ไฟล์เกิน 10 MB — ย่อรูปก่อน |
| ขึ้นว่าชนิดไฟล์ไม่อนุญาต | รองรับ jpg, png, gif, webp, pdf และเอกสารสำนักงาน |
| อัปโหลดได้แต่ไม่แสดง | เลือกไฟล์ผ่าน File Manager ไม่ใช่วางลิงก์เอง |
| เคยขึ้นแล้วหาย | แจ้งผู้ให้บริการ — อาจเป็นเรื่องพื้นที่จัดเก็บ |

---

## เว็บขึ้นว่า "ยังไม่พร้อมให้บริการ"

เว็บยังไม่เคย **Build Runtime** หรือ snapshot หาย — แจ้งผู้ให้บริการ

---

## Google ยังหาเว็บไม่เจอ

1. ตรวจว่า **Robots** ไม่ได้ตั้งเป็น `noindex` (หน้า SEO)
2. เปิด `https://โดเมนของคุณ/sitemap.xml` ต้องเห็นรายการหน้า
3. ส่ง sitemap เข้า Google Search Console
4. **รอ** — Google ใช้เวลาหลายวันถึงหลายสัปดาห์

> เว็บสร้างหน้าฝั่งเซิร์ฟเวอร์อยู่แล้ว Google อ่านเนื้อหาได้ทันทีโดยไม่ต้องรัน JavaScript
