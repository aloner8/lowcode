| คู่มือ | สำหรับใคร | ทำอะไรได้ |
|---|---|---|
| [01-god.md](01-god.md) | **GOD** — พนักงานหนุมานไอที | สร้างเว็บใหม่ ตั้งค่าทุกเว็บ กำหนดแพ็กเกจ ดูแลความปลอดภัย |
| [02-admin.md](02-admin.md) | **ADMIN** — ผู้ดูแลระบบของหน่วยงาน | เพิ่มผู้ใช้ในหน่วยงาน ตั้งค่าเว็บของตัวเอง ดูวันหมดอายุ |

## สิทธิ์ทำอะไรได้บ้าง

| งาน | GOD | ADMIN | STAFF |
|---|:---:|:---:|:---:|
| สร้าง Platform / เว็บไซต์ใหม่ | ✅ | — | — |
| กำหนดแพ็กเกจและวันหมดอายุ | ✅ | ดูได้ | ดูได้ |
| ตั้งค่าธีม / SEO / โดเมน ของเว็บตัวเอง | ✅ | ✅ | — |
| เพิ่ม–ถอดผู้ใช้ในหน่วยงาน | ✅ | ✅ | — |
| เพิ่มข่าว แก้ไขหน้าเว็บ | ✅ | ✅ | ✅ |
| เข้า DesignStudio | ✅ | — | — |
| ตั้งค่าความปลอดภัยของระบบ | ✅ | — | — |

**GOD** เป็นสิทธิ์ระดับระบบ ส่วน **ADMIN / STAFF ผูกกับเว็บไซต์เสมอ** — คนเดียวเป็น ADMIN
ของเว็บหนึ่งและ STAFF ของอีกเว็บได้

## เข้าระบบครั้งแรก

1. เปิดลิงก์ที่ได้รับ แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่ผู้ดูแลให้มา
2. ระบบจะพาไปหน้า **เปลี่ยนรหัสผ่าน** ทันที — เป็นขั้นตอนบังคับ ข้ามไม่ได้
3. ตั้งรหัสใหม่อย่างน้อย 8 ตัวอักษร (ระบบจะบอกความแข็งแรงให้ระหว่างพิมพ์)
4. บันทึกแล้วเข้าใช้งานได้ตามปกติ

> ตราบใดที่ยังไม่เปลี่ยนรหัสเริ่มต้น ทุกหน้าจะเด้งกลับมาที่หน้านี้เสมอ
