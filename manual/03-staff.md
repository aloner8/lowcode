# คู่มือ STAFF — เจ้าหน้าที่ของหน่วยงาน

หน้าที่หลักคือ **เพิ่มข่าว** และ **แก้ไขหน้าเว็บ** ของหน่วยงาน

---

## 1. เข้าใช้งานครั้งแรก

1. เปิดลิงก์ที่ผู้ดูแลของหน่วยงานส่งให้
2. เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่ได้รับ
3. ระบบจะพาไปหน้า **เปลี่ยนรหัสผ่าน** — ตั้งรหัสของคุณเอง (อย่างน้อย 8 ตัว)
4. เสร็จแล้วเข้าใช้งานได้

> ถ้าลืมรหัสผ่าน ให้ติดต่อ **ผู้ดูแลระบบของหน่วยงาน** (ADMIN) ไม่ใช่ผู้ให้บริการ

---

## 2. เพิ่มข่าว

ข่าวแบ่งเป็นหมวด เช่น **ข่าวประชาสัมพันธ์** และ **ข่าวกิจกรรม**

| ช่อง | ใส่อะไร |
|---|---|
| หัวข้อ | ชื่อข่าว — ขึ้นทั้งหน้าแรกและหน้ารายการ |
| รายละเอียด | เนื้อข่าว จัดรูปแบบและแทรกรูปได้ |
| หมวดหมู่ | เลือกให้ตรง เพราะกำหนดว่าข่าวจะไปโผล่หน้าไหน |
| รูปภาพ | รูปหน้าปกข่าว |
| วันที่เผยแพร่ | เรียงลำดับข่าวตามช่องนี้ |
| สถานะ | ต้องเป็น **เผยแพร่** ข่าวจึงจะขึ้นเว็บ |

### เขียนหัวข้อให้ดี

- เขียนให้ชัดว่าเรื่องอะไร — ประชาชนเห็นแค่หัวข้อตอนค้นหา
- ใส่ปีหรือช่วงเวลาถ้าเกี่ยวข้อง เช่น "ประจำปีงบประมาณ 2569"
- ❌ "ประกาศ" · "แจ้งเพื่อทราบ" — สั้นเกินจนไม่รู้ว่าเรื่องอะไร
- ✅ "ประกาศรับสมัครพนักงานจ้าง ประจำปีงบประมาณ 2569"

### ใส่รูป

- ใช้ **File Manager** เลือกหรืออัปโหลด ไม่ต้องวางลิงก์เอง
- **ใส่คำบรรยายภาพทุกครั้ง** — คนตาบอดใช้โปรแกรมอ่านหน้าจอ และช่วยให้ Google เข้าใจภาพ
- ไฟล์ไม่ควรเกิน 10 MB · ย่อรูปก่อนอัปโหลดเพื่อให้เว็บโหลดเร็ว

> ไฟล์ที่อัปโหลดเก็บแยกเฉพาะหน่วยงานของคุณ หน่วยงานอื่นเข้าถึงไม่ได้

---

## 3. แก้ไขหน้าเว็บ

หน้าอย่าง "เกี่ยวกับเรา" หรือ "ติดต่อเรา" แก้ข้อความและรูปได้โดยตรง

**ข้อควรระวัง**

- แก้แล้ว **กดบันทึกทุกครั้ง** ออกจากหน้าโดยไม่บันทึกจะหาย
- อย่าลบส่วนที่ไม่แน่ใจ ถ้าไม่ต้องการให้แสดง ให้ปรึกษา ADMIN ก่อน
- ใช้ **หัวข้อ** (Heading) แบ่งเนื้อหา อย่าใช้ตัวหนาตัวใหญ่แทน — โปรแกรมอ่านหน้าจอและ Google ใช้หัวข้อในการเข้าใจโครงสร้าง

---

## 4. ทำไมแก้แล้วเว็บยังไม่เปลี่ยน

**ข่าวที่เพิ่มใหม่ขึ้นทันที** ไม่ต้องทำอะไรเพิ่ม

แต่การเปลี่ยน**โครงสร้างหน้า** ต้องให้ผู้ให้บริการกด Build Runtime ก่อน

| แก้อะไร | ขึ้นเว็บเมื่อไหร่ |
|---|---|
| เพิ่ม/แก้/ลบข่าว | ทันที |
| แก้ข้อความในหน้าเว็บ | ทันที |
| เปลี่ยนโครงสร้างหน้า เพิ่มเมนู | ต้อง Build Runtime |
| เปลี่ยนธีมหรือสี | ต้องรีเฟรชหน้า |

ถ้าแก้ข่าวแล้วยังไม่ขึ้น ให้ตรวจ 3 อย่างนี้ก่อน

1. **สถานะ** เป็น "เผยแพร่" หรือยัง
2. **วันที่เผยแพร่** เป็นอนาคตหรือเปล่า
3. **หมวดหมู่** ตรงกับหน้าที่กำลังดูไหม

## 5. สิ่งที่คุณทำไม่ได้ (และต้องขอใคร)

| อยากทำ | ติดต่อ |
|---|---|
| เพิ่มผู้ใช้ใหม่ | ADMIN ของหน่วยงาน |
| เปลี่ยนสีหรือธีมเว็บ | ADMIN ของหน่วยงาน |
| เพิ่มโดเมน | ADMIN → ผู้ให้บริการ |
| เพิ่มเมนูหรือหน้าใหม่ | ADMIN → ผู้ให้บริการ |
| ต่ออายุแพ็กเกจ | ADMIN → ผู้ให้บริการ |
